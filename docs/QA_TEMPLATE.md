# QA checklist

- Build or commit, URL, browser, and viewport
- Register, verify email, sign in, reload dashboard, sign out, reset password
- Test enabled Google, Telegram, and chatbot features
- Test the main workflow with valid, missing, and invalid inputs
- Confirm role and ownership checks on restricted API calls
- Test link navigation, direct visits, back button, and narrow layouts
- Check health and readiness on the deployed URL

For a bug, record steps, expected and actual results, severity, browser, and the request ID if available. Remove credentials and codes from screenshots and logs.
